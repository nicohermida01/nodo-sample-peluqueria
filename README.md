# NUDO Estudio de Pelo

Sitio de demostración (y template) de una peluquería ficticia en Palermo, CABA. Astro 7 + Tailwind 4, estático.

```sh
npm install
npm run dev     # http://localhost:4321
npm run build   # dist/
```

Datos de marca en `src/config/site.ts`; servicios, equipo y galería en `src/content/`. Guía completa en `CLAUDE.md`.
